# Agents Cleaner

Codex, Claude Code, Gemini CLI, Orca, Herdr가 PC에 쌓아 둔 기록과 캐시를 프로젝트별 목록으로 보여 주고, 체크한 것만 백업 없이 정리하는 Windows용 프로그램입니다.

Herdr는 `%LOCALAPPDATA%\herdr-core\<프로필>`의 터미널 목록을 조회하고 `core.log`·`holder.log`를 정리합니다. 터미널 상태·화면·앱 설정은 보존하며, 종료된 터미널 제거는 Herdr의 `hc rm <ID>`를 사용하세요. Herdr에서 실행한 Codex·Claude 대화는 기존 원본 저장소에서 표시되며, Codex 추가 계정은 `~/.codex/accounts/<ID>`에서 찾습니다. Herdr 앱이나 core 서버만 떠 있으면 AI 기록은 삭제할 수 있고, 작업 폴더 삭제와 Herdr 자체 로그 정리만 차단합니다. Herdr 안에서 실행 중인 에이전트는 그 앱의 프로세스로 따로 감지되어 잠깁니다. 창을 닫아도 서버는 남을 수 있으며, '실행 중 앱'의 종료 버튼이 `hc server stop`까지 처리합니다.

## 실행

Python 3.11 이상이 필요합니다.

```
py -3.11 -m pip install -r requirements.txt
py -3.11 scripts/main.py              # 정리
py -3.11 scripts/main.py --read-only  # 목록만 보기
py -3.11 scripts/main.py --inventory  # 개수만 출력 (제목·내용 없음)
```

탐색기에서 `실행.cmd` 또는 `읽기전용.cmd`를 더블클릭해도 됩니다. PySide6가 없으면 기본 Tkinter 화면으로 실행됩니다. Tkinter 화면에는 앱 종료와 자동 갱신이 없고 앱 단위로 잠급니다.

## 지우는 방식

| 대상 | 방식 |
|---|---|
| Codex 대화 | 공식 `codex delete` 명령으로 영구 삭제 (백업 없음, 복구 불가) |
| Claude Code · Gemini 대화 | 백업 없이 Windows 휴지통으로 이동 |
| 캐시·로그 | 정해진 폴더만 백업 없이 휴지통으로 이동 |
| 작업 폴더 | '작업 폴더' 열에서 따로 체크한 경우에만, 그 폴더의 대화를 모두 지운 뒤 휴지통으로 이동 |

로그인 정보, 설정, Claude 프로젝트 메모리, Codex 프로젝트 등록, Orca 프로젝트 등록은 지우지 않습니다.

## 실행 중인 앱 닫기

'실행 중 앱'에서 앱별로 프로세스 수, 창 유무, 실행 중인 에이전트, 메모리를 보고 바로 종료할 수 있습니다.

1. 확인을 받은 뒤 창을 닫고, Herdr는 `hc server stop`을 실행하고, 최대 10초 기다립니다.
2. 그래도 남은 프로세스는 목록을 보여 주고 다시 확인받은 뒤 하위 프로세스까지 강제 종료합니다.

자동으로 종료하는 일은 없습니다. 이 프로그램을 띄운 앱(예: Herdr 터미널에서 실행한 경우 Herdr)은 닫을 수 없으니 탐색기에서 `실행.cmd`로 실행하세요. 읽기 전용 모드에는 종료 버튼이 없습니다.

앱이 켜지거나 꺼지면 2초 안에 잠금이 바뀌며, 목록과 선택은 유지됩니다. 새로 잠긴 항목만 선택에서 빠집니다. 종료 버튼으로 앱을 닫으면 앱이 마지막으로 저장한 내용을 반영하려고 목록을 다시 읽으므로 선택이 초기화됩니다.

## 안전장치

- 실행 중인 앱의 기록은 삭제할 수 없으며, 삭제 직전에도 다시 확인합니다. 잠금 범위는 다음과 같습니다.

| 실행 중 | 잠기는 기록 |
|---|---|
| Codex, Gemini | 그 앱의 기록 전체 |
| Claude 데스크톱만 | Claude 캐시·로그 (대화는 잠기지 않음) |
| Claude Code (세션 파일로 대화를 특정할 수 있을 때) | 그 대화와 Claude 캐시·로그 |
| Claude Code (특정할 수 없을 때, 예: Herdr에서 실행) | Claude 기록 전체 |
| Orca | Orca가 관리할 수 있는 계정의 기록 |
| Herdr | Herdr 자체 로그 |

- 프로세스 확인에 실패하면 모든 기록을 잠급니다.
- Orca, Herdr, Claude Code 세션이 실행 중이면 작업 폴더는 삭제할 수 없습니다.
- 드라이브 루트, 사용자 폴더, 바탕화면·문서·다운로드 자체, 시스템·설치 폴더, AI 앱 저장소, 링크·junction은 작업 폴더로 지울 수 없습니다.
- 작업 폴더가 git 저장소이면 커밋하지 않은 변경, push하지 않은 커밋, 원격 없음을 경고합니다.
- 삭제 전 확인 창에서 확인 체크를 해야 진행됩니다.

휴지통을 비워야 이동한 파일의 디스크 공간이 실제로 늘어납니다. '백업 관리'에서는 이전 버전이 만든 백업을 정리할 수 있습니다.
